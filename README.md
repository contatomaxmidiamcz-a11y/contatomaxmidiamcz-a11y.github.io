# Maxmídia — site

Landing page da Maxmídia, agência de marketing digital.

- Página única: `index.html` (sem dependências; imagens e logos embutidos no arquivo).
- Publicação: GitHub Pages, a partir da branch `main`, pasta raiz.

## Como atualizar
1. Substitua o `index.html` pela nova versão (no GitHub: **Add file › Upload files**).
2. Faça o commit. O GitHub Pages publica de novo em 1–2 minutos.

## Antes de publicar
Preencha os campos entre colchetes nas páginas legais e no rodapé: razão social, CNPJ, endereço, encarregado de dados (DPO) e cidade do foro.
